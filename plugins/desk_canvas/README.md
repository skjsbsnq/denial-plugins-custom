# Desk Canvas

个人桌面图标与真实文件插件，包名 `desk_canvas`，贡献 ID `desk_canvas.desktop`。与 [App Shelf](../app_shelf/README.md) 和任务栏独立安装，通过真实桌面文件夹协作，不依赖其他 UI 插件。

## 已实现

- 显示系统 XDG 桌面目录中的真实文件、文件夹、链接和应用 `.desktop`；目录变化通过事件合并更新，不轮询。
- 读取本地化应用名称，复用 SDK 解析主题图标，并在后台 isolate 缓存图标路径；无法解析时显示回退图标。
- 图标标签按 Windows 10 桌面排版：白色文字、柔和深色阴影、无底角色块、两行内省略；字体与 CJK 回退来自宿主 `ShellTextTheme`。快捷方式隐藏 `.desktop` 后缀，入口缺少 `Name` 时退回文件名主干，普通文件保留真实文件名；快捷方式左下角是白底箭头标记。
- 鼠标按下即选择，避免等待双击识别；Ctrl / Shift 点击多选，空白拖动框选，双击打开；悬停显示浅强调色底，选中显示强调色底与描边；方向键、Ctrl+A、Enter、F2、Delete、F5、Esc。
- 桌面内部拖动图标，释放后对齐网格、处理碰撞并保存位置；图标较多时水平滚动，键盘选择会滚动到对应列。
- 空白右键：新建文件夹、打开桌面文件夹、刷新、按名称整理、显示隐藏文件，以及“小 / 中 / 大”三档图标大小（当前档高亮）。
- 项目右键：打开、重命名、移入回收站（多选时显示数量）、查看路径。删除前确认，使用系统回收站，不自动永久删除。
- 右键菜单不叠加全屏遮罩，桌面亮度保持不变；菜单即时出现（不做淡入淡出），背景模糊从第一帧就存在；在别处再次右键会直接把菜单移到光标位置，左键空白处或 Esc 关闭，键盘可依次聚焦菜单项。
- 加载、失效链接、目录权限、损坏入口、操作失败和配置保存失败均有反馈。目录配置修复、桌面目录删除后重建可由事件恢复。

桌面文件只显示在**主显示器的工作区**，避免多屏重复。其他屏幕继续保留壁纸；主屏切换后在新主屏恢复，并将越界位置重新排列。插件不修改桌面时钟、窗口预览、任务栏或系统设置，不提供第二个工作区预留。

## 选择反馈与性能

选中边框改为独立背景绘制，选中与取消都不改变前景内边距，避免图标和文字移动 1 px。每个项目独立处理悬停，只过渡背景，不缩放或重采样图标文字；沿用公开 `Motion.pill`、宿主动画速度与系统关闭动画设置，支持移入后快速移出。小于半格的拖动不改位置，也不保存布局。

桌面仅在文件元数据、图标大小、工作区尺寸或用户排布变化时重新排布；图标和文字缓存为稳定前景，悬停不重建整桌面或弹层。移除桌面对整份宿主应用目录的无用订阅，真实启动时按需读取。初始空位分配改为向前单次遍历；水平滚动通过按列索引直接取得当前视口及两侧一列的项目，避免每次滚动遍历全目录；拖动项在出视口后仍保持挂载。拖动复用公开 SDK `RetainedTranslation`，逐帧仅更新绘制变换和命中位置，前景不构建、不布局，释放时才计算落点并保存；不改变轨迹或图标采样清晰度。

背景过渡保持原有 `DecorationTween` 插值与曲线，改为仅通知局部 `CustomPainter` 重绘；入口整体及静态前景各有绘制边界。没有更改模糊、透明度、阴影、字体、圆角、图标尺寸、动画时长或曲线。真实目录扫描和入口校验仍执行，但复用元数据未变的项目与列表，避免无关文件变化让全部图标失去缓存；字段、错误、路径或目录类型变化会使缓存失效。稳定宿主主题的 Material 转换也会复用。以上消除代码中可确认的额外工作，尚未进行真实桌面帧率测量。

## 独立审查后的交互修正

右键目标仅在菜单交互期间保持选择；菜单取消、执行菜单操作并关闭、接受打开操作或转到应用窗口后清理对应的选择与悬停。单击选择、Ctrl/Shift 多选、框选和键盘操作仍保留。清理后只有新的真实鼠标移动会恢复悬停，布局或弹层变化合成的进入事件（即使携带旧 delta）不会点亮旧图标。新一轮桌面操作有独立代次，旧窗口焦点回调或旧菜单关闭回调不会清除新选择／新菜单；已取消的拖动也不会再落点保存。外部入口仍须确认，接受运行时先释放弹层的焦点恢复请求，避免应用打开后桌面再抢焦点。

框选矩形改为独立绘制通知，选择集合未变化时不重建图标；命中检测先按列筛选，再验证实际矩形与滚动坐标，拖动取消或桌面隐藏会清除选择框。批量图标落点复用集合和单向空位游标，保持原碰撞排布结果。目录刷新合并扫描期间的重复请求，每个调用等待覆盖自身请求的一轮；卸载时先分离监听快照再异步取消，修复刷新与卸载并发修改监听列表的竞态。

桌面菜单仅提前收尾自身持有的 closing ID，绝不遍历并结束其他插件的弹层；避免控制中心等面板突然收尾或焦点跳转。本轮没有修改材质、阴影、图标采样、动画曲线和持续时间。尚未进行真实桌面帧率测量。

## 重绘范围与后台开销

宿主挂载 surface 时没有提供绘制边界，桌面图标层的任何一次重绘都会扩散到整帧场景（含壁纸）。桌面现在自带最外层绘制边界，把重绘限制在自身工作区内；全屏窗口覆盖工作区时桌面层不再保持可见合成，仅在概览或“显示桌面”需要时绘制。

右键菜单原先跟随画布每次 `setState` 重建，拖动、框选和选择变化都会重新创建背景模糊与抗锯齿裁剪；现在只有菜单实际绘制的内容变化才重建。目录重扫在没有可见差异时不再触发整棵图标树重建。图标名解析结果在进程内长期缓存并串行成批，不再为每批新名称新建冷缓存 isolate。

已安装应用目录改为打开快捷方式时按需读取一次，不再读取会常驻应用目录 watcher 与周期重扫的共享控制器；桌面项目变化后该缓存失效。高亮画笔复用同一插值动画，并按当前装饰值判断是否需要重绘。以上均为失效范围与缓存调整，没有更改材质、阴影、字体、圆角、图标档位和动画参数；实际帧率与显存占用仍需在桌面上确认。

## 应用快捷方式

App Shelf 的“发送快捷方式到桌面”写入完整 `.desktop` 副本；Desk Canvas 监听到后显示。也支持在文件管理器中把实际文件放进桌面文件夹。删除快捷方式只删除这份桌面文件，不卸载应用。

与 SDK 应用目录中来源文件名称和内容完全一致的入口，优先使用宿主应用启动服务。D-Bus 激活、终端入口以及 SDK 没有收录的独立入口由集中 GIO 适配器按文件路径启动，保留系统 `.desktop` 语义；不自行拆分或 shell 执行 `Exec`。独立导入或修改过的快捷方式每次运行前提示确认，不写入私有“信任”元数据。找不到应用、终端或默认关联程序时显示系统返回的错误。

依赖目标 Linux 的 `gio` 命令（GIO / GLib）。默认应用打开和回收站能力不在当前 SDK 公开服务中，故集中在 `GioFileActions`。GIO 启动与 Denial 的窗口焦点、启动反馈及默认终端的实际配合仍需用户桌面验证。

## 目录、配置与交互边界

读取 `${XDG_CONFIG_HOME:-$HOME/.config}/user-dirs.dirs`，支持 `$HOME`、中文目录和规范引号转义，不执行 shell。未配置桌面项时使用 `$HOME/Desktop`；显式设为主目录表示禁用，绝不把整个 HOME 展示为桌面。HOME 或 XDG_CONFIG_HOME 无效时在任何文件读取或监听之前报告错误。缺失桌面目录显示错误，可在文件管理器创建，或从 App Shelf 发送快捷方式时创建。

布局保存在 `${XDG_CONFIG_HOME:-$HOME/.config}/desk_canvas/layout.json`：版本、文件名到网格坐标、图标大小、隐藏文件偏好。它不存储实际文件内容。重命名通过 Linux `renameat2(RENAME_NOREPLACE)` 原子执行；不覆盖同名文件，系统不支持该接口时明确失败。

桌面背景沿用宿主已有的输入路由，不注册覆盖原生窗口的整屏输入区域。菜单与确认框交给 SDK 管理临时输入、关闭与焦点恢复，跟随宿主明暗、强调色、字体、圆角、透明度和模糊。菜单使用透明遮罩并关闭 SDK 的外点关闭策略，由菜单自身处理空白点按、再次右键和 Esc，因此不会在右键时压暗整屏；确认框仍保留轻量遮罩以区分模态操作。菜单行高、分隔线、左图标和三档图标大小按 Windows 10 密度排版，文字使用宿主字体。用户已关闭桌面时钟和最小化窗口预览，此插件不代替用户修改它们。

当前不包括：跨应用鼠标拖入拖出、文件剪切复制粘贴互通、缩略图、撤销、批量重命名，以及分别把文件分配到多个显示器。原生跨应用文件拖放需要公开 SDK 的数据交换支持；桌面内部拖动仅改变图标位置。

## 源码与检查

```text
lib/desk_canvas.dart                 主屏桌面层贡献与显示策略
lib/src/desktop_canvas.dart          选择、排布、键盘、菜单及确认界面
lib/src/desktop_store.dart           有界入口解析、XDG 目录、事件与文件状态
lib/src/desktop_sdk_adapter.dart     SDK 图标解析与已安装入口比较
lib/src/desktop_viewport.dart        按列索引的可见项目查询
lib/src/highlight_decoration.dart    仅重绘的背景过渡
lib/src/rename_no_replace.dart       Linux 原子无覆盖重命名
test/desktop_store_test.dart         临时目录中的无界面回归检查
test/interaction_highlight_test.dart 悬停反向与选中位置控件检查
docs/ARCHITECTURE.md                 数据、生命周期与实现边界
```

按[集合开发准备说明](../../docs/DEVELOPMENT.md)选择与目标 Denial 匹配的工具链，在本插件目录运行：

```sh
"$PLUGIN_FLUTTER" pub get
"$PLUGIN_DART" format --output=none --set-exit-if-changed lib test
"$PLUGIN_DART" analyze --fatal-infos lib test
"$PLUGIN_DART" test/desktop_store_test.dart
"$PLUGIN_DART" run test/desktop_viewport_test.dart
"$PLUGIN_DART" run test/desktop_feedback_test.dart
"$PLUGIN_DART" run test/refresh_coalescing_test.dart
"$PLUGIN_DART" --packages=.dart_tool/package_config.json ../../tools/check_desktop_integration.dart
"$PLUGIN_FLUTTER" test test/interaction_highlight_test.dart test/desktop_interaction_test.dart --reporter expanded
```

回归检查只在临时目录操作，不启动软件、不访问用户桌面、不调用真实回收站。覆盖配置禁用、解析和大小限制、监听更新、损坏配置恢复、目录重建、重命名冲突与位置衔接、布局边界、卸载和跨插件快捷方式写入。视口索引回归逐项对比原有全扫描的可见项目及叠放顺序，并覆盖边界列、出屏拖动项和元数据变化。控件检查增加装饰插值一致和动画 tick 不重建绘制委托的断言。纯 Dart 检查还覆盖临时悬停重置、合成进入抑制、原批量落点结果、突发刷新合并及监听卸载竞态。新增控件检查使用假存储、假文件操作和假窗口投影，覆盖双击、菜单关闭、窗口激活后的反馈清理及旧 delta 合成进入；不访问真实桌面或启动应用。控件检查需要套件提供 `flutter_tester`；本机缺少该程序，已尝试执行但未能加载测试，不能视为通过。静态与无界面检查不能确认实际视觉效果、原生焦点或帧率；这些由用户验证。

## 安装与来源

本地来源添加、候选构建与激活是独立步骤；本插件代码不会自动改变插件选择。启用时保留现有任务栏，按需同时选择 App Shelf。候选需要使用当前源码重新生成、构建；操作说明见根 README。

本插件为个人新实现，使用公开 SDK，没有复制官方桌面 UI 或 SDK 源码。设计依据为本机 SDK 和[插件系统契约](https://github.com/denialwm/denial/blob/dev/docs/PLUGIN_SYSTEM.md)。按 GPL-3.0-or-later 分发，见 [LICENSE](LICENSE)。
