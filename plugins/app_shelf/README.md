# App Shelf

个人应用启动器，包名 `app_shelf`，拥有独立的界面和右键菜单。它与 [Desk Canvas](../desk_canvas/README.md) 分别选择、独立安装，不依赖官方启动器或自定义任务栏。

## 已实现

- 搜索应用名称及宿主提供的搜索元数据，展示真实应用名称和图标。
- 所有应用按字母分组，非拉丁首字母归入 `#`，不猜测中文拼音；右侧磁贴展示最多 9 个真实最近使用应用，无记录时展示应用速览。启动通过宿主 `onLaunch`，沿用启动与历史记录能力。
- 按 Windows 10 开始菜单重排为 48 px 左导航栏、36 px 字母分组应用列表、右侧方形磁贴和底部搜索框。宽度小于 580 px 或搜索中收起磁贴，列表与磁贴分别滚动；保留右键发送桌面、键盘导航与提示。磁贴是最近使用／速览入口，不是可编辑的固定磁贴，也不伪造动态内容。
- 搜索更改、清空和重新打开时恢复列表顶部。单击启动；上下键逐行、PageUp/PageDown 翻页、Home/End 跳到两端；Tab 在搜索框与列表之间切换；Enter 启动；菜单键或 Shift+F10 打开当前应用菜单，菜单内上下键选择并用 Enter 执行；Esc 先关闭菜单，再关闭启动器。列表右侧是细滚动条，键盘移动会滚动到选中项。
- 应用右键菜单提供“打开”和“发送快捷方式到桌面”，使用同样的紧凑行样式。找不到真实 `.desktop` 的内部应用禁用发送并说明原因。菜单局限在启动器内部并按空间收拢；再次右键其他应用会直接把菜单移到该应用，点击空白处、搜索框或其他控件时关闭。
- 发送时从公开共享应用状态按公开身份函数取得真实入口，完整复制到 XDG 桌面目录，保留原文件名、中文字段、启动参数及附加动作。
- 同一副本提示已存在；同名不同内容或符号链接报告冲突，不覆盖。应用升级后需要更新副本时，请先在桌面移走旧副本后再次发送。
- 发送过程显示状态并限制重复操作，失败显示错误；关闭后的迟到结果不更新新一轮界面。退出中的界面隔离指针及键盘焦点。

外观使用宿主明暗、强调色、字体、圆角和面板色。文字样式全部由宿主 `ShellTextTheme` 派生，因此沿用用户选择的字体及其 CJK 回退，不再退回打包的 Material 默认字体。标题、搜索框、列表和菜单都按面板尺寸自适应，低高度时列表滚动。搜索框使用 `cardColor(surfaceContainerHigh)` 与宿主小圆角边框，选中/悬停使用强调色角色，面板圆角与描边取宿主 `panelRadius` 与 `hairline`。

面板材质与官方 **App Launcher** 完全一致：只画 `panelColor(panelBackground)` 的圆角矩形加 `hairline` 描边，**不在客户端再叠加 `ShellBackdropBlur`**。启动器由宿主作为独立窗口合成，桌面背景与玻璃模糊由合成器统一提供；客户端自己再加一层背景滤镜会与合成冲突，实测表现为“一边是壁纸、一边纯黑”的硬边。去掉该滤镜后，面板重新跟随 `panelOpacity` / 玻璃透明度，整块颜色一致，开合时的透明度过渡也不会再出现背景缺失。

## 视觉参考与性能

本次布局参考微软公开的 [Windows 10 开始菜单示例图](https://learn.microsoft.com/en-us/windows/configuration/start/images/windows-10.png)及[开始菜单结构说明](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-windows-start-menu)中的 Windows 10 部分（2026-10-23 查阅）。借鉴导航栏、字母列表与磁贴的比例和密度，明暗、字体、强调色、透明度、圆角和材质继续取 Denial 设置，不复制 Windows 固定颜色或图片资源。

应用目录仅在宿主应用快照变化时预计算名称、搜索元数据、字母分组和排序；每次搜索只筛选预处理结果，最近记录变化复用全部应用及分组行。稳定主题的 Material 转换缓存复用，宿主主题变化立即失效。

应用身份与字母分组到列表行的映射随索引一次生成，搜索使用独立映射，最近记录变化复用已有映射。焦点、键盘选择及菜单更新时，已保留行直接查表恢复位置，避免逐行扫描整个应用目录；不改变图标保留预算、滚动轨迹或视觉效果。

悬停由每个入口本地处理，背景用与原先 `AnimatedContainer` 相同的 `DecorationTween` 和 `BoxDecoration` 绘制，但动画 tick 仅通知 `CustomPainter`，不再逐帧构建控件或触发布局。整个入口与静态前景分别设绘制边界，限制重绘范围并保持前景清晰。悬停还要求真实指针位移：列表滚动后鼠标跟踪器可能用携带旧位移的合成进入事件点亮刚滑到指针下的行，现在只有实际移动才恢复反馈，启动器隐藏时会复位全部入口。菜单的指针与键盘选中值改为独立通知，鼠标在菜单两项之间移动只重建菜单内容，不再重建整块面板和它的阴影。反馈时长仍取公开 `Motion.pill` 与宿主动画速度，尊重系统关闭动画设置；颜色、圆角、边框、阴影、材质、布局和动画曲线未降级。发送动作按需读取共享应用目录，启动器不为悬停订阅整份目录状态。初次图标加载仍由 SDK 承担；这些改动不能单独证明桌面帧率。

## 滚动与开合动画差异

应用列表和磁贴区分别使用阻尼滚动控制器：鼠标滚轮连续输入累加目标，反向时取消未完成的同向距离并继承当前速度；键盘定位按最终目标计算，快速 Home/End 改向不会继续跑到旧位置。滚动范围变化时重新约束目标，菜单打开或启动器隐藏时停止惯性。公开事件识别为触控板的滚动及原生平移手势继续由 Flutter 处理，关闭动画时使用原生即时响应；输入设备被系统统一报告为鼠标时无法额外区分高精度触控板。

列表保留最多 32 个已访问行的 keep-alive 租约，磁贴保留最多 8 个；超出预算的离屏项释放，已删除或被搜索排除的项目正常卸载。保留的是 SDK 原图标加载器的状态，不另建图标缓存、改变分辨率或替换图标。稳定应用身份与重排映射避免排序、搜索更新时把旧图标状态错接到另一应用；控制器和保留状态随插件卸载清理。

本机控制中心和电池面板共用 `PanelMotion` 的临界阻尼展开动画，前景不缩放、不淡化；启动器外层由宿主 `DesktopPanelTransition` 管理，根据锚点使用整体滑入或淡入，采用另一套曲线。当前公开 `LauncherContext` 只有可见性，没有外层过渡进度、完成通知或自定义过渡入口，插件不能完整替换这层效果；本轮改进滚动与图标挂载开销，**没有把启动器外层动画改成控制中心同款**。完整统一需宿主提供相应接口或修改宿主实现；不改写 SDK／上游参考副本、不改变用户面板锚点设置。

## 快捷方式与文件

桌面目录读取 `$XDG_CONFIG_HOME/user-dirs.dirs`（默认 `~/.config/user-dirs.dirs`），支持 `$HOME`、`${HOME}` 以及中文路径；未配置时使用 `~/Desktop`，明确禁用为 HOME 时拒绝写入。文件内容作为数据解析，不执行配置文件中的 shell 表达式。

入口最大 256 KiB；配置最大 64 KiB；读取有界。采用同桌面文件系统的私有临时目录写入完整内容，再使用 `ln -T --` 独占发布，避免覆盖并发出现的文件。临时目录会清理。需要系统提供标准 `ln` 工具；缺失或文件系统不支持硬链接时明确报错。不会启动应用来验证，不修改来源文件、权限或添加其他桌面环境专属信任属性。

Desk Canvas 通过真实文件夹事件发现快捷方式；即使未启用 Desk Canvas，发送仍然有效。桌面文件的打开、位置和文件操作由桌面插件负责。

## 宿主边界

`ShellLauncher` 是零或一个提供者的独占契约，启用本插件时需要关闭官方 **App Launcher** 或其他启动器提供者。外部位置、面板大小、开合动画、输入捕获由宿主管理，公开 `ShellLauncher` 没有重设原生窗口锚点的接口；本次重构只改变面板内部布局。动作 ID 为 `app_shelf.openApplications`，可在宿主快捷键设置中绑定；不迁移原启动器快捷键。

应用发现、图标和最近记录来自宿主；没有新增目录扫描或轮询。简化上下文没有入口路径，发送仅使用公开 `homeGridControllerProvider` 中存在的完整入口。当前 SDK 应用发现排除的终端入口仍然不可用；缺失的元数据会禁用发送，不按名称猜测文件路径。

## 开发与检查

按[集合开发准备说明](../../docs/DEVELOPMENT.md)设置匹配工具链和本机 SDK overrides，然后在本插件目录运行：

```sh
"$PLUGIN_FLUTTER" pub get
"$PLUGIN_DART" format --output=none --set-exit-if-changed lib test
"$PLUGIN_DART" analyze --fatal-infos lib test
"$PLUGIN_DART" run test/shortcut_writer_test.dart
"$PLUGIN_DART" run test/launcher_logic_test.dart
"$PLUGIN_DART" run test/scroll_motion_test.dart
"$PLUGIN_FLUTTER" test test/interaction_highlight_test.dart test/smooth_scroll_test.dart --reporter expanded
```

回归检查使用纯 Dart 和临时目录，覆盖完整副本、中文及 `%` 路径、重复、冲突、符号链接、无效/超限入口、禁用目录、shell 表达式、并发发送、预检后目标变成目录或目录符号链接的真实发布竞态，以及最近排序、搜索、网格边界、滚动计算、预处理读取次数、目录索引复用及缓存查询结果。纯 Dart 检查另覆盖连续滚动目标、反向位置／速度连续、边界、动画速度及有界保留租约。滚动控件检查覆盖实际指针信号解析、原生触控板分支、减少动画、快速定位改向、运行中卸载及保留预算。控件回归检查覆盖悬停局部更新、中途反向、选中前后内容位置不变，以及动画 tick 不替换绘制委托、插值结果与原装饰一致；需要编译套件包含 `flutter_tester`。当前本机套件缺少该可执行文件，已尝试运行但未能加载测试，不能当作通过。没有执行桌面视觉或真实应用启动验证；静态分析与无界面检查不代表桌面效果已确认。

实现细节见[设计说明](docs/ARCHITECTURE.md)。本插件未自动添加来源、改变选择或激活；集成候选由集合流程独立处理。
